# 固定的 BridgeMod 发布输入

此目录保存 AMCL 随包分发的 0.2.0 八个 JAR。`manifest.json` 是文件名、加载器、游戏版本及 SHA256 的单一清单。

CI 和本地准备脚本只从此目录复制，不回退下载历史 0.1.0。`bridge-mod/dist` 是可重新生成的构建目录，不提交。运行时的历史在线下载兜底独立保留。

更新流程：修改源码、编译对应目标、验证功能、将新 JAR 复制到本目录并更新清单；运行完整测试和发布输入预检。不要只改校验值来绕过失败。

2026-10-13：八个目标完成 Windows 单人世界允许/拒绝天气命令共 16 项实测。随后 Forge 1.12.2 仅修正版本注解并重新编译，新增发布输入回归验证注解与 SHA256；真实游戏原始报告记录其测试时的 JAR 哈希。
