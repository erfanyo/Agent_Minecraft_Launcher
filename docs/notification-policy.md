# 1.1.0 提示分类（测试候选）

`ui_notifications.py` 提供明确的呈现接口，不全局替换 QMessageBox。

| 类型 | 入口 | 位置 |
| --- | --- | --- |
| 下载、导出、安装、备份等结果/失败 | task_notice / task_warning | 状态球任务页，非阻塞 |
| 输入错误、缺少选择、名称/目录不可用 | inline_notice / inline_warning | 当前操作位置的反馈卡片 |
| 删除、强制结束、多开等即时确认 | action_question | 操作附近，点击确认/取消，Esc 或点外面取消 |
| 后台任务等待确认 | task_question / request_confirmation | 状态球确认卡片，问题排队 |

AI 交互、文件选择、正版授权、EULA 阅读保持专用界面。没有任务中心时，接口回退到原生 QMessageBox，独立组件不用构造整个主窗口。

## 体验回退

设置 → 系统 → **任务提示集中到状态球**。关闭保存 `ui_task_notifications=false`，恢复传统提示窗口；状态球仍承载任务、日志和进度。

## 本轮范围

已迁移首页、资源、实例、维护、导出、服务端与设置页面的主要提示调用，路由记录位于 `.tmp/notification-routing-audit.tsv`。配置输入、文件选择与完整协议阅读不简化成普通确认。

整合包 ZIP / CurseForge ZIP / Modrinth mrpack 改为后台打包，先快照 UI 选项。任务取消是协作式，先在临时目录生成压缩包，再独占创建目标，已有文件不会被覆盖。进度按当前阶段计算，未知工作量保持忙碌状态。

## 扩展约定

新功能明确选择接口，不靠错误文字做全局自动分类。多个步骤沿用 task_id，准备完成不是任务完成。待确认回调 None 表示撤销，不得继续后续操作。即时确认与 AI 审批不要挂到后台队列。

离屏自动化覆盖分类与回退；真实桌面焦点、窗口层级、Wayland 系统拖动和新提示是否顺手仍需体验反馈。
