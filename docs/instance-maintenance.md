# 实例维护与高级启动选项

实例详情的「概览」提供修补核心、补全文件、重置；AI 使用同一套服务，需要写权限和操作确认。

- 修补核心：重新安装当前 MC 和加载器版本，备份后替换启动核心。无法识别原版本时停止，让用户在「修改」指定，不猜测升级。
- 补全文件：按版本清单校验并补下载客户端、依赖和资源；不重新下载第三方 Mod。
- 重置：仅备份并移走 launch_options.json、options.txt、optionsof.txt，保留存档、Mod、Mod 配置。关闭版本隔离时不执行，避免影响共享设置。
- 修改：填写 MC 版本，选择原版 / Forge / Fabric / NeoForge，可指定加载器版本。临时安装成功后才替换现有实例核心，保留实例名称和目录。导入整合包会提醒兼容性风险；不会自动升级 Mod 或转换存档。

核心和设置备份位于游戏目录的 `versions/_maintenance/<实例>-<随机编号>`。操作结果给出完整路径。退出游戏后可将备份文件复制回对应实例目录；这是核心/设置备份，不是存档备份。修改版本前请另做存档备份，尤其不要直接降级打开世界。

全局设置和实例设置都有默认折叠的「高级设置选项」。实例默认继承全局 JVM 参数，也可取消继承单独填写（空白表示仅默认参数）。额外参数不经过命令行 shell。内存请在内存区域设置，不接受重复的 -Xmx/-Xms。第三方参数不保证适合当前 Java，启动异常时先清空再试。

维护期间禁止通过启动器启动游戏；执行维护前也检查已运行的 Java。界面不会主动关闭游戏或第三方应用。
