# HY-MT2 实测与语言包审核

日期：2026-10-26。模型通过用户本机 LM Studio `http://127.0.0.1:1234/v1` 调用，实际响应模型为 `hy-mt2-7b`。只发送源码中的界面文案，不读取或发送账号、API 密钥、聊天记录或整合包内容。没有替换启动器的聊天/描述翻译模型配置。

## 对翻译水平的判断

适合界面初译，不能无人校对后直接视为成品。最初十条英语样本约11.5秒，覆盖短按钮、长说明、Minecraft术语、HTML和占位符。这是当时本机状态下的观察，不是模型性能基准；用户随后调整功耗策略，生成速度变化不作为故障判断。

实际发现并修正的问题：

- “恢复所有不再提示”过于直译成 `Restore all 'no prompt' settings`，采用 `Restore all dismissed notices`。
- 一条英语安全说明错误地把“不要运行包内程序”和“不会自动导入”连接成因果关系，保留两项独立含义。
- 日语把“需要当前模型支持看图”误译成“不支持看图”，已校正为必须具备图片输入能力。
- 俄语把云端模型优先理解成云存储优先，把日志回收理解成释放内存；已统一为模型路由与日志保存/删除。
- 个别提供商品牌归属错误、韩语夹杂汉字、同一大厅混用Hall/Lobby，以及操作按钮误用“正在检查”的进行时，已校对关键项目。
- 批量JSON偶尔漏项、非JSON输出或改变HTML；用长度、占位符、HTML和URL校验拒绝，拆小批重试，复杂HTML按标签外文本分段翻译。

这些是本项目样本中的观察，不代表完整基准分数或与其他模型的排名。非英语语言仍需母语用户继续校对，因此保留预览版标记。

## 已交付范围

英语、日语、韩语、法语、西班牙语、俄语、阿拉伯语每包1,670条，共11,690条语言条目。英语以既有较好译文为基础，HY-MT2补译并校对；其他六种由HY-MT2扩译并抽查修正。不会为了切换界面语言而要求用户运行模型。

1,527条已登记的静态翻译源（含指令库显示名称与参数说明）全部有译文。全部语言包的占位符、受保护HTML/URL/确认语检查通过。数字单位“秒/天”、网盘根目录与原版加载器标签也已接入。这个覆盖率不包括未登记的后台状态、异常原文、用户资源描述和AI自然语言回复，不能宣称全应用绝无中文。

英语截图审核覆盖设置全部章节、实例详情全部章节、资源浏览器、网盘下载窗口。当前检查状态中没有未处理的静态中文；语言自称、用户文件名及代码/NBT示例中的文本不作为待翻译界面文案。未模拟每一种网络失败、每个第三方插件或游戏运行状态。

随后生成七种语言、深浅主题的182个设置页状态，并额外捕获长页面底部；抽查六种语言的排版与关键文字。韩语无界面截图曾缺字，补充加载本机Malgun Gothic后重新检查；仅影响截图工具字体，不捆绑字体或修改系统字体。截图中俄语个别页面最小宽度约1238px，是预览版后续小窗口适配点；不宣称所有缩放和窗口宽度已经验收。

阿拉伯语增加RTL启动布局。各包基础语言改为自身语言，避免继续误用中文基础语言同步Minecraft。语言切换仍需重启，当前用户选择未被改动。

指令库显示文本与原始类别/模板ID分离：翻译标签不会改变命令、NBT模板、文件路径或用户自定义名称。新增英语/日语/阿拉伯语UI回归验证选择模板后仍生成原始游戏命令。

## 工具和复现

- `tools/localize_ui.py`：扫描明确的UI参数，把已有译文接入`t()`；不是全局字符串替换。仅改变显示文字，保留模型工具Schema、业务标识和指令内容。
- `tools/language_pack.py`：导出当前翻译源及引用位置、检查缺译与格式占位符。
- `tools/translate_ui_lmstudio.py`：只向固定本机LM Studio地址发送UI文本，默认两路并发；草稿逐批保存到`.tmp/hymt2-multilingual/`，不自动覆盖发布语言包，可续跑。其他模型或服务必须显式指定，不读取启动器凭证。
- `tools/capture_language_preview.py`：用无账号的样例设置生成截图，不下载资源、不调用模型。可选语言和主题，阿拉伯语使用RTL。

截图目录：`.tmp/english-residual-review/`（英语实例、资源和网盘）、`.tmp/multilingual-review-final/`（七语设置）、`.tmp/multilingual-review-korean-final/`（韩语字体修正后）。最终数据校验：`.tmp/hymt2-multilingual/final-validation.json`。原始英语样本：`.tmp/hymt2-sample.json`。

完整回归：925项单元测试通过、1项显式可见WebView测试跳过，另70项子测试通过；115项UI测试通过。最终语言数据与占位符另做全包检查。未打包EXE或发布。

参考：[腾讯Hy-MT2官方说明](https://github.com/Tencent-Hunyuan/Hy-MT2/blob/main/README_CN.md)。厂商提供术语、格式与分隔符约束范例，本项目依然以实际界面表现和本地校验为准。
