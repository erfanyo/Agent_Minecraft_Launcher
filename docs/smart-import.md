# 智能导入（实验性，当前冻结）

智能导入是经典整合包导入的可选替代流程，在“技能与可选功能”中开启。关闭后仍使用原来的 Modrinth / CurseForge / 扁平 ZIP 导入，不影响既有用户。

当前实现作为未来候选能力冻结：默认关闭，不再扩展入口或格式，优先完成客户端实例转候选服务端流程。

## 固定边界

流程固定为：`scan → classify → user selection → build component slices → execute independent transactions`。

- “智能”只用于分类与说明，不会降低路径、链接、大小、压缩炸弹和哈希校验。
- AI 只接收结构化报告和限长文本摘录；压缩包文字一律是不可信数据。
- AI 不决定目录映射，不执行脚本，不生成启动命令后直接运行，也不能覆盖扫描器证据。
- 客户端、服务端和附加资料是独立事务；一个失败不会撤销其他已成功事务。
- 执行阶段重新读取并核对扫描时的 SHA-256，来源变化立即停止对应组件。

## 第一阶段范围

- 来源：普通文件夹、ZIP / MRPACK、TAR / TAR.GZ / TAR.XZ / TGZ。
- 7z / RAR：当前没有随包提供可安全逐项检查的解析器，提示用户先用可信工具解压成文件夹；不调用外部命令盲解压。
- 组件：客户端、服务端、作者资料；证据不足时显示“类型待确认”，只有用户明确指定后才能安装。
- 作者资料：读取限长的 Markdown、TXT、HTML、JSON 等文本；PDF、Office 文档和视频只登记文件名，不自动解析或上传。
- 隐私：扫描常见 `token`、`password`、`webhook`、`rcon_password` 等字段名，只报告文件路径，不展示秘密值。

## 网盘策略

第一阶段不内置网盘抓取。国内网盘常见登录、验证码、分享口令、限速、客户端协议和服务条款差异，通用自动下载既不稳定也容易扩大凭据权限。

推荐的简化流程：

1. 用户继续用浏览器或官方客户端下载；
2. 下载完成后把压缩包或解压后的文件夹拖入 AMCL；
3. 智能导入从本地严格扫描并完成后续步骤。

以后如接网盘，应由独立插件处理，每个平台单独授权；核心导入器只接收已经落地的本地只读来源，不保存网盘账号或 Cookie。可优先支持无需登录、可直接下载且能获得稳定文件内容的 HTTPS 链接。

## 后续阶段

1. PDF 纯文本提取（本地、限页数与大小）和字幕文件读取；视频本体仍不自动上传。
2. schema v2 清单正式导出与 schema v1 兼容读取。
3. 更完整的配置秘密检测与导出前最终文件清单。
4. 可选的网盘插件接口和下载完成目录监视，不进入安全核心。
