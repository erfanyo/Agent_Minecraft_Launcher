# UI 阶段评估与英语预览包

评估时间：2026-10-26。后续已完成HY-MT2实测、英语补漏和六语扩译，当前交付与验证以[翻译审核记录](hymt2-translation-review.md)为准；下面保留最初英语预览阶段的评估过程，不代表最终条目数量。不是全部桌面流程的人工验收。

## 成熟度判断

主观上约 7/10：已经有可持续使用的产品结构，适合发布英语预览；尚不适合宣称完整国际化或冻结全部文案。

- 布局：实例、资源、设置等主入口明确；设置章节、标题、开关和深浅主题已形成统一样式。主要设置页可以作为阶段性基线。
- 交互：后台任务、进度、取消、错误接续和局部确认都有基础。网盘凭证与下载等新流程仍在变化，AI 高级设置也较复杂，需要继续验收。
- 文案：主要导航、设置标签、实例详情操作足够稳定，值得开始翻译。长说明、动态错误、开发者功能和部分混合术语仍需继续收敛。
- 国际化：旧语言包各114条，很多新控件未调用翻译入口。不能用旧语言包数量推断全界面覆盖率。

本轮截图额外发现 `refresh_theme()` 缺少 QApplication 导入，异常被吞掉，导致默认控件调色板可能不随主题刷新；已补齐导入并重生成深浅主题截图。

## 英语预览

入口：设置 → 语言 → English (preview)，重启生效。没有替用户修改当前语言。

- `languages/en.json` 共383条；沿用旧译文，优先采用集中表已有英文，再补充并校对本轮界面译文。
- 设置、实例详情、首页新增201处翻译入口，之后补齐主要设置提示和内存预算动态文本。没有对用户资源名称、文件路径、指令内容或模型提示词作全局替换。
- 修正英语包基础语言误设为中文，保证 Minecraft 语言同步依据英语基础语言处理；启动时加载包后重新解析 auto，让英语系统也能使用英语覆盖层。
- 语言下拉不再重复列出英语；当前包名称明确标注 preview。
- 已登记的352条静态翻译源均有英语译文，变量占位符检查通过。此数字只覆盖 `t()` 调用与集中字符串表；不包括未接入的硬编码文本，不能表述为全UI覆盖100%。
- 网盘接续、部分AI/高级页面、部分动态状态、长说明及原生对话框仍可能显示中文。其他既有语言包没有重做。

## 可复用的维护入口

`tools/language_pack.py --export languages/source_zh.json --audit languages/en.json` 从当前源码导出翻译源与引用位置，检查缺译和变量占位符。工具不发送网络请求、不加载模型、不读取账号配置。中文原文改变会成为新键，并在审计中显示缺译。

语言包属于构建时产品资源，不需要用户为了切换语言再安装模型。后续翻译服务可用于维护语言包，但不应让启动器每次绘制按钮时联网翻译。

## HY-MT2 与并发核对

[腾讯官方 Hy-MT2 说明](https://github.com/Tencent-Hunyuan/Hy-MT2/blob/main/README_CN.md)列出1.8B、7B、30B-A3B型号、33种语言，以及术语、格式和占位符约束用法。适合作为后续语言包初译候选；质量结论仍需实际界面短句和Minecraft术语样本验证，不能仅凭厂商榜单宣称更好。

最初仅查看启动器模型目录，找到Qwen，未检查LM Studio，因此当时“未找到HY-MT2”的判断范围不足。用户指出后通过本机LM Studio找到并实测`hy-mt2-7b`，最终英语包已包含其补译结果。没有自动下载权重、替换聊天模型、运行外部skill或调用收费接口。原Mod描述翻译仍沿用既有配置。

当前代码中未找到独立的翻译并发设置。资源图片队列并发4和整合包下载线程池属于其他任务，不能当成翻译并发。用户记忆中的历史调整可能位于旧工具、外部推理服务或其他配置，本轮没有查证其位置，也未擅自覆盖。

后续实际使用HY-MT2批量翻译时，先小批评估，再按推理服务承载能力设置并发；模型输出必须经过缺译、占位符和界面长度检查，保留人工校对环节。
