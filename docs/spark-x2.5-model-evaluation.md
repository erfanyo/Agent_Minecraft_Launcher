# Spark X2.5 内置模型评测

评测日期：2026-09-12

## 结论

暂不把 `spark-x2.5-1.7b` 接成 AMCL 的内置操作模型。它可以保留为未来纯聊天、解释类模型的候选；在当前由单个模型同时负责对话和工具调用的架构中，使用它会降低启动器操作的成功率。

## 对照条件

- 接口：LM Studio OpenAI 兼容接口
- 测试集：`ai_testset.py` 中的 31 条中文启动器指令
- 运行次数：每条指令 3 次，共 93 次请求
- 解码设置：temperature 0
- 工具定义：与 2026-08-23 两个 Qwen 候选评测相同
- Spark 模型：`spark-x2.5-1.7b`，本地文件约 1.11 GB
- Qwen xLAM：`qwen3.5-0.8b-xlam-q4km`，本地文件约 529 MB

| 模型 | 工具名准确率 | 参数准确率 | 综合得分 |
|---|---:|---:|---:|
| Spark X2.5 1.7B | 45.2% | 48.4% | 46.8% |
| Qwen3.5 0.8B 通用版 | 51.6% | 51.6% | 51.6% |
| Qwen3.5 0.8B xLAM | 74.2% | 69.4% | 71.8% |

Spark 的三轮输出完全一致，未出现接口异常，因此低分不能归因于随机波动。93 次请求中有 18 次只返回文字、没有调用工具。主要失败集中在安装 Mod、发送游戏指令、查询配方、修改设置和需要调用 `ask_user` 追问的场景。

## 适用范围

这套评测衡量的是单步工具选择与参数填写，不能代表一般聊天质量，也不能证明模型具备连续诊断和修复能力。只有候选模型在本轮达到可接受水平后，才值得进入隔离静态修复、超预算续接和真实启动验证。

若以后加入独立的意图路由，让聊天模型不直接控制工具，可以另行评测 Spark 的 Minecraft 问答、日志解释和中文表达质量。在此之前不随安装包分发该模型，以免额外增加约 1.11 GB 下载和运行负担。
