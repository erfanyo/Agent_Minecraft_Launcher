## 一、目标与方向

- **不要**静态说明页(第一版"按页面讲控件"已临时弃用,见 `deprecated_features.py` / 灵感 #7)。
- **要**"引导式教程"(coach marks / guided tour):**指着真实 UI,一步步引导**——目标控件处挖洞高亮 + 箭头 + 说明气泡,用户跟着走一步做一步。
- **必然跟着 UI 改**,所以**框架要通用、内容要数据驱动**(步骤=数据,框架只负责按数据画到目标上)。

## 二、架构

```
内容(纯数据)              framework(通用)               UI 定位
tutorial_steps →         guide_overlay.GuideDriver  →  ui_route.resolve
  [{route,arrow,text}]     (spotlight 遮罩+气泡+按钮)    (逻辑route→真实控件)
```

### 1) 步骤数据(纯数据,框架不关心具体 UI)
```python
step = {
  "route": [("maintab","我的版本"), ("btn","启动游戏")],   # 怎么定位到控件
  "arrow": "below",        # 气泡/箭头方位
  "text": "点这里启动你选中的实例……",
}
```
- UI 改了只改 `route`/文案;`GuideDriver`/`GuideOverlay` 不动。
- ⚠️ **待定**:步骤从哪来?内置 `tutorial_steps.py`(静态数据)还是支持"运行中动态发现控件"?先做静态。

### 2) 定位器 `ui_route.py`(核心)
- `resolve(main_window, route)` → `(target_widget, top_window)`。
- route 段(类型, key):
  - `("maintab", "我的版本"|"下载新资源"|"设置")` — 切换主标签页取该页 widget
  - `("btn", 按钮文本)` — 在父控件里找文本/objectName 匹配的按钮(串找 QPushButton/QToolButton)
  - `("widgetname", "someName")` — 按 objectName 找子孙控件
  - `("sub", 索引)` — 高级取第 N 个 child(少用)
- ⚠️ **待定/不确定**:
  - route 词汇表够不够覆盖所有要引导的控件(下拉/列表/菜单/对话框)?
  - 是否改用"稳定 objectName + `ui_handles` 注册表"更稳(重命名才要改)?现在按文本找(改名就崩)。
  - `btn` 用"文本含"匹配可能误伤(多个含"设置"的按钮);要不要精确匹配 + objectName 优先?

### 3) 遮罩渲染 `guide_overlay.py`
- 顶层无框窗口(`FramelessWindowHint | Tool | WindowStaysOnTopHint`),`WA_TranslucentBackground`,定位到目标窗口上方。
- paintEvent:用 `QPainterPath` 调暗整块、在目标控件处**挖洞**(subtracted rounded rect)+ 外框高亮;再画**箭头 + 气泡**。
- 底部控制条:上一步 / 下一步 / 完成。
- 目标窗口移动/改尺寸 → 重算几何跟随。
- ⚠️ **待定**:遮罩是否让点击"穿过"到高亮控件(spotlight 洞可点)还是整块拦截(演示版是拦截,只让按钮可点)。做成"洞可点"要加 masks/区域判定。

### 4) 驱动 `GuideDriver`
- 持有步骤列表 + 当前下标;`start()/next()/prev()/finish()`;定位不到某步 → 自动跳过。
- 发射 `finished` 信号。

## 三、关键难题 & 现状

### 1) 模态对话框(第 4 点)—— **现在通过 UI 现代化解决**
- 旧:设置 / 实例管理是 `dlg.exec()` **模态**,模态会挡住同应用其它窗口输入,引导遮罩无法在上面正常操作。
- 方案:**把设置、实例详情改成"顶部平级标签卡 / 非模态面板"**(和「下载新资源」同布局),这样引导遮罩可以直接覆盖它们、指到其内部控件。
- ⚠️ **待定**:有些内容(如"实例详情"是每实例一个)做成 tab 还是"非模态窗口"?tab 只能开一个;实例详情要随选中实例切换。目前**实例详情仍是模态对话框,只改了名叫「实例详情」**。

### 2) UI 现代化(正在做,`CenterShell`)
- 目标:设置 / 实例详情 / 下载新资源 **统一为"左菜单(纵向)+ 右侧面板"**。
- **`CenterShell`**:左侧 `QListWidget`(菜单项)+ 右侧 `QStackedWidget`(对应面板)+ 可展开/收起;面板由调用方按 menu index 提供。
- **设置 → 顶部标签卡**(`SettingsCenter`,左菜单 游戏/界面/AI助手/镜像源 → 右面板;底部"保存"):解决模态 + 纵向排列。
- **实例详情 → 左菜单+右面板**(复用现有各 tab 内容 `_build_*_tab`)。
- ⚠️ **待定**:设置从"弹窗确定保存"改成"标签页常驻",保存时机?改项即存 vs 底部「保存」按钮;与 `AISettingsForm` 的联动。
