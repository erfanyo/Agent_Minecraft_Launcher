# 本体功能与可选扩展

正式功能随本体发布，由 `launcher_app/features/registry.py` 的固定清单注册：

- 联机：陶瓦与 EasyTier 页面常驻联机中心，组件按用户操作下载和启动。
- 浏览器助手：设置中的独立入口，连接仍由用户主动授权。
- Create 原理图、TaCZ 枪包、车万女仆模型、YSM 皮肤、Hotai 补丁：
  安装对应 Mod 的实例自动显示管理分区，不再询问是否启用插件。
- KubeJS：本体只读脚本查看和报错定位入口。

这些功能不是从 `plugins/` 扫描的外部代码，不受旧 `plugins_enabled`、
`plugins_disabled` 或插件发现提示影响。实现复用内部工具、页面和资源分区接口，
保留原工具名及 `plugin.<旧ID>.*` 配置键以复用已有配置和组件路径。
这是兼容数据格式，不代表功能仍是可停用插件。

MCP Server 保留为默认关闭的可选插件。示例 hello 与旧版性能监控样例移到
`plugins_templates/`；性能监控样例使用旧接口，未作为正式功能发布。
默认插件目录和官方清单仅保留 MCP。实验与第三方扩展仍可使用插件机制。

加载器忽略与内置功能同名的旧插件文件，并拒绝通过插件安装接口覆盖内置功能。
内置功能先注册，避免外部扩展抢占其名称。默认关闭的外部插件先通过静态元数据
判断是否启用，不再为了读启用状态而执行顶层代码。

Windows 与 Linux 打包配置显式收集 `launcher_app.features`，不依赖松散插件文件。
这次迁移没有实现新的插件沙箱或商店签名审核系统；现有第三方 Python 插件仍是可信代码模型。
