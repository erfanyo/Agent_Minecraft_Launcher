# 插件分类与分享码

设置中的插件分为可展开的「Mod 管理」和「功能」。未知插件默认归入功能。
官方 Mod 管理插件：Create 原理图、Hotai 补丁、KubeJS、TACZ 枪包、女仆模型包、YSM 皮肤。

分享码格式：`AMCLPLUGIN1:` 加上 UTF-8 JSON 的 URL-safe Base64，省略末尾填充。

JSON 字段：

- `registry`：HTTPS 仓库主页或插件清单链接。
- `plugin`：清单里的插件 ID，仅允许字母、数字和下划线。
- `category`：`Mod 管理` 或 `功能`，只影响展示。

插件位置由清单的 `download_url` 指定，分享码不重复编码文件路径。
解析分享码只查询清单、显示插件和来源；用户点击安装后才下载插件。
分享码不包含账户、密钥，不代表签名或可信认证。
仓库源管理保留在插件商店的「高级：仓库源」入口，已有源不迁移、不删除。
更新格式时使用新的前缀版本；保留旧版解析，不悄悄改变已有分享码的含义。
