# 公开网页读取

Agent 内置 `read_public_webpage(url)`，不依赖 Node.js、MCP 或浏览器扩展。
工具始终挂载，网页任务优先尝试 HTTP；B站视频先尝试公开元数据接口，失败再读页面，
短链先经过受限跳转解析。标题、作者、简介和时间不等于作者最新动态或下载内容已核验。
需要登录、评论或动态内容时，继续使用浏览器；读取失败不能推断来源不存在。

设置 → AI 助手可编辑“公开网页允许的域名”，默认 `bilibili.com,b23.tv`。
每个条目允许该域名及其子域名，空列表禁用全部访问。不支持通配符、IP、端口或路径。
Agent 的修改设置工具不能改动网页授权范围，需用户在界面修改。

## 实施边界

- 只允许 HTTP/HTTPS 的默认端口和匿名 GET。不接受请求头、Cookie、密钥、请求体或其他方法。
  不读取浏览器会话，不使用系统代理或 netrc，不执行 JavaScript，不保存下载文件。
- 每次 DNS 解析检查全部结果，仅允许公网地址；连接固定到已检查的 IP。
  HTTPS 保留原域名的 Host/SNI 与证书验证，阻止跳转降级和 DNS 重绑定。
  拒绝本机、私网、链路本地、共享地址、保留地址及 IPv6 映射/转换地址。
- 最多四次跳转，每跳重新检查授权域名和解析地址。B站短链外跳到其他平台不会自动放行。
- 响应最多 1 MiB，只接受 HTML、纯文本和 JSON；拒绝压缩响应，避免解压炸弹。
  单次请求连接/读取等待上限 8 秒，跳转链按 25 秒预算读取；系统 DNS 的阻塞时间由操作系统控制。
- HTML 移除脚本和样式，正文限长，链接数封顶。结果脱敏并标记为不可信网页资料。

这不是任意联网权限。允许列表仍需谨慎设置：访问会向目标站点暴露 IP 和请求内容，
GET 也不保证目标服务绝无副作用；不要把秘密拼入 URL。网页提示注入无法仅靠内容标签根除，
现有写操作确认和浏览器权限控制仍然适用。不应为绕过站点验证而关闭这些边界。
