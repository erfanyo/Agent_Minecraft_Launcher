# 作者偏好与项目语气

记录时间：2026-10-26。用户原话与已确认产品规则应在后续维护中保留，避免每次会话重复确认。

- 作者原话：“虽然下服务端的是少数，而且下载服务端的人大概不回来用这个功能，但是万一能把人拖进mc的深渊呢”。产品含义：不隐藏服务端候选，先找到最新客户端和服务端，再通过 `ask_user` 让用户选择，默认推荐客户端。
- 作者原话：“能不转存尽量不转存，具体看用户习惯，万一用户是给好友分享转存后的链接”。直接下载优先，明确请求的转存和分享仍是合理目标，不作一刀切禁止。
- 作者原话：“交给用户，正常人下载个资源摸索摸索大概还是会的”。遇到登录、验证码或必须用客户端时，给出简明接续信息，不无限自动重试，也不把人工接续描绘成失败。
- 作者的俏皮表达可用于助手、注释和更新说明；保持少量自然，错误、风险和确认文字保持清楚准确。
- 网盘能力尽量通过 HTTP 完成；浏览器用于必要的登录授权和页面兜底。原始 ZIP/MRPACK 永久保留，方便分享。
- 作者本机使用火绒。系统安全中心未登记某个杀软，不代表它未安装或未运行。尊重用户明确说明，不擅自启用 Defender、修改火绒配置或猜测第三方扫描命令；本机额外 Defender 扫描开关已关闭。

## 会话入口

2026-10-29：程序主动发给助手的提示/任务显示为独立的 **AMCL** 发言（展示条目 `amcl`），不冒充用户，也不覆盖未发送的文字/图片。`AIChatDock.ask()` 用于这一入口；手动输入继续显示为用户。归档/恢复保留 AMCL 身份。模型侧使用普通 user 消息并标注 `name=AMCL`，而不是无效的自定义 API role 或新的高优先级 system 指令；网页、分享文案、日志等外部内容不因此获得系统权限。

开发协作：根目录 `AGENTS.md` 引用本文。DeepSeekHarness 是否自动加载该文件取决于其具体配置；当前没有验证其配置，不宣称它会自动读取。可将“开始工作前读取仓库 AGENTS.md 及其引用的偏好文档”加入该 harness 的项目系统提示或启动上下文。

启动器内助手：`main.py` 的 `ai_context()` 调用 `plain_language_instructions()` 并注入启用技能的 `ai_hints()`。项目语气通过前者注入；选包、转存和人工接续规则在默认启用的整合包追查技能中。关闭该技能时不会注入其技能规则。
