# 运行日志回收

设置 → AI 助手提供自动回收开关、保留天数、容量上限和“立即按规则清理”。
默认开启，保留 30 天、容量上限 100 MB（按 1024 × 1024 字节计算）。

启用运行记录时，自动回收在 AI 任务开始时检查（开始检查最多每小时一次），任务结束后再次检查。
先删除超过保留时间的已结束日志；若容量仍超限，再从最旧的已结束日志开始删除。
当前任务的记录受到保护，直到后续回收检查。时间依据日志文件最后修改时间。
关闭自动回收仍可手动按当前规则清理。

仅处理 `AMCL/ai_runs/` 中 UUID 命名的 `.jsonl` 普通文件，且最后一条记录必须
带有匹配的 run_id、schema 和 `finish` 标记。未结束、损坏、格式不明、扫描后发生变化的
记录与链接文件不删除；无法删除的文件保留并计入失败数量。
受保护记录本身超过上限时，不强制删除，界面会说明容量仍超限。

回收不涉及聊天归档、训练样本、AI 操作审计、备份、恢复点或游戏文件。
删除原始日志后无法恢复对应的详细运行过程。此回收规则不判断模型回答是否正确，
也不会把“对话已结束”误当作“安装或下载已验证成功”。
